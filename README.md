# CSS Image Gallery with Sidebar Menu

A CSS-based mini project created while learning and practicing CSS
concepts. The project combines a full-screen image gallery with a
collapsible sidebar navigation menu over a background image.

The main focus of this project was to practice CSS layout, positioning,
transitions, styling, and a pure-CSS menu toggle using a checkbox.

## Features

-   Full-screen image gallery layout
-   Collapsible sidebar navigation
-   Hamburger menu to open the sidebar
-   Close button to hide the sidebar
-   Gallery containing four nature-themed images
-   Image cards with descriptions
-   Hover effects on menu items and social icons
-   Responsive viewport meta configuration
-   Custom background image
-   Sidebar with social media icons
-   Google Fonts and icon libraries integration

## How the Sidebar Works

The sidebar menu uses a **checkbox-based CSS toggle** instead of
JavaScript.

A checkbox is connected to the menu controls using the `label` element.
When the checkbox is checked, CSS changes the sidebar position using
`transform: translateX(...)`, hiding it from the screen. The same
mechanism is used to show the hamburger button.

This helped me understand how CSS selectors, form controls, and
state-based styling can be combined to create interactive UI components
without JavaScript.

## Gallery Layout

The image section uses **CSS Grid** to arrange the gallery into two
columns and two rows. Each image is placed inside a styled card
containing the image and a short description.

The project includes four nature-themed images:

-   Garden pathway surrounded by flowers
-   Pink blossoms
-   Colorful wildflower meadow
-   Lotus garden
